# Car-Gallery & Customizer HTML5, CSS3, Bootstrap 5 JavaScript(jQuery for dynamic functionality) 

The Car Customizer Website allows users to explore, customize, and view car details interactively. It features a multi-step customization process, a dedicated car profile page, and a modern, responsive design.

# Features
Multi-Step Customization Process:

Select car models, colors, and accessories.
View a summary of the selected configurations.
Dynamic Car Profile Page:

Displays detailed car information such as price, model, and specifications.
Uses URL parameters to dynamically populate content.

# Modern Design:
Clean, gradient-based UI with handwritten fonts for a stylish look.

# Responsive Layout:
Mobile and tablet-friendly design for seamless user experience.

# Technologies Used
Frontend: HTML5, CSS3, Bootstrap 5
JavaScript: Vanilla JavaScript (jQuery for dynamic functionality)
Fonts: Google Fonts (Dancing Script)
